# Syntecxhub_E-Commerce-Store
# 🛒 ShopNova - E-Commerce Store

A full-stack e-commerce web application built using **React, Vite, Node.js, Express.js, and MongoDB**.

ShopNova provides a complete online shopping experience with product browsing, search, categories, wishlist, cart, checkout, order tracking, and an admin dashboard.

---

## 🚀 Features

### 👤 User Features

- User Registration & Login
- JWT-based Authentication
- Browse Products
- Product Search
- Category Filtering
- Product Sorting
- Add to Cart
- Update Cart Quantity
- Remove Products from Cart
- Wishlist
- Checkout
- Cash on Delivery (COD)
- Shipping Address
- Order Placement
- Order History
- Order Status Tracking

### 🛠️ Admin Features

- Admin Authentication
- Admin Dashboard
- Sales & Order Statistics
- Product Management
- Add Products
- Update Products
- Delete Products
- Stock Management
- Order Management
- Update Order Status
- Customer Management
